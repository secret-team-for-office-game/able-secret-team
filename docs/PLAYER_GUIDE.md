# คู่มือผู้เล่น — THE ABLE SECRET TEAM

## เริ่มเล่น
1. แจ้งชื่อ + ร่วมบริจาค CSR กับผู้ดูแลกิจกรรม (นอกระบบ)
2. รับรหัสพนักงาน + รหัสผ่านจากผู้ดูแล
3. เข้าเว็บ → กรอกรหัสพนักงาน + รหัสผ่าน → เข้าเกมได้ทันที

ระบบสุ่มคุณเข้า 1 ใน 3 ทีมลับ (🐬 โลมา / 🐳 วาฬ / 🦈 ฉลาม) — **ห้ามบอกใครว่าคุณอยู่ทีมไหน!**

## ทุกสัปดาห์
- **วันพฤหัส:** เข้าแท็บ "🗳️ โหวต" เลือก 1 คนที่คิดว่าเป็นทีมศัตรู (เลือกได้ครั้งเดียว เปลี่ยนไม่ได้)
- **วันศุกร์:** Admin ประกาศผล — โหวตถูกทีม +10 คะแนน, โหวตทีมเดียวกัน -5 คะแนน
  (คุณจะไม่รู้ว่าตัวเองโหวตถูกหรือผิดเป็นรายบุคคล เห็นแค่คะแนนสะสมรวม)
- คนที่โดนโหวตว่าน่าสงสัยเยอะสุดจะถูกคัดออกเป็น **Ghost Mode** (ยัง login/ดูผลได้ แต่โหวตไม่ได้)

## การ์ดพิเศษ (แท็บ 🃏 การ์ด)
ทุกคนได้ **Revive Card** ฟรี 1 ใบตอนเริ่ม อยากได้เพิ่มติดต่อ Admin (จ่ายเงินนอกระบบ):
- 💗 **Revive** — ช่วยเพื่อนที่เพิ่งเป็น Ghost กลับมา Active
- 🔮 **Reveal** — ส่องดูทีมของใคร 1 คน (เห็นแค่คุณคนเดียว เขาไม่รู้ว่าถูกส่อง)
- 🔄 **Team Switch** — สุ่มย้ายตัวเองไปอีกทีม (เป็นความลับ คะแนนเดิมไม่หาย)
