# คู่มือผู้เล่น — THE ABLE SECRET TEAM

## เริ่มเล่น
1. แจ้งชื่อ + ร่วมบริจาค CSR กับผู้ดูแลกิจกรรม (นอกระบบ)
2. รับรหัสพนักงาน + รหัสผ่านจากผู้ดูแล
3. เข้าเว็บ → กรอกรหัสพนักงาน + รหัสผ่าน → เข้าเกมได้ทันที

ระบบสุ่มคุณเข้า 1 ใน 3 ทีมลับ (🐬 โลมา / 🐳 วาฬ / 🦈 ฉลาม) — **ห้ามบอกใครว่าคุณอยู่ทีมไหน!**

## ทุกสัปดาห์
- **วันพฤหัส:** เข้าแท็บ "🗳️ โหวต" เลือก 1 คนที่คิดว่าเป็นทีมศัตรู (เลือกได้ครั้งเดียว เปลี่ยนไม่ได้)
- **วันศุกร์:** Admin ประกาศผล — โหวตถูกทีม +10 คะแนน, โหวตทีมเดียวกัน -5 คะแนน
  **และถ้าเพื่อนร่วมทีมโหวตหาคุณผิดๆ (โหวตทีมเดียวกัน) คุณก็โดนหัก -5 คะแนนไปด้วย**
  (หักครั้งเดียวต่อสัปดาห์ไม่ว่าจะโดนกี่คน) — คุณจะไม่รู้ว่าตัวเองโหวตถูกหรือผิดเป็นรายบุคคล เห็นแค่คะแนนสะสมรวม
- คนที่โดนโหวตว่าน่าสงสัยเยอะสุดจะถูกคัดออกเป็น **Ghost Mode** (ยัง login/ดูผลได้ แต่โหวตไม่ได้)

## ถ้าคุณถูกคัดออก (เสียชีวิต)
หน้า "ทีมฉัน" และ "โหวต" จะแสดงข้อความ:
> 💀 คุณเสียชีวิตแล้ว หากต้องการชุบชีวิต กรุณาติดต่อ Admin พร้อมแจ้ง Username หลังโอนเงิน

**การชุบชีวิตทำผ่าน Admin เท่านั้น** — ไม่มีการ์ดหรือระบบซื้อชุบชีวิตในเว็บ
ติดต่อ Admin นอกระบบ (ไลน์/เงินสด) แล้ว Admin จะกดชุบชีวิตให้จากฝั่งเขา คุณจะกลับมา Active ทันที
