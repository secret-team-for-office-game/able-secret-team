# คู่มือ Admin — THE ABLE SECRET TEAM

## เข้าใช้งาน
`/admin` (ต้องเป็น role `admin` หรือ `super_admin`) — ดู `docs/SETUP.md` สำหรับสร้าง Super Admin คนแรก

## งานตั้งต้น: รับสมาชิกใหม่
1. เก็บเงินบริจาค CSR นอกระบบ (ไลน์/เงินสด)
2. แท็บ **"➕ สร้างผู้เล่น"** → กรอกรหัสพนักงาน + รหัสผ่านเริ่มต้น + ชื่อ
3. ระบบสุ่มเข้าทีมอัตโนมัติ (เกลี่ยจำนวนให้เท่ากัน) + แจกการ์ด Revive ฟรี 1 ใบ
4. ส่งรหัสพนักงาน+รหัสผ่านให้ผู้เล่นทางช่องทางที่ปลอดภัย — **ห้ามบอกว่าทีมไหน**

## วงจรรายสัปดาห์ (พฤหัส–ศุกร์)
1. แท็บ **"รอบ & โหวต"** → กด **"เปิดโหวต →"** (วันพฤหัส)
2. รอผู้เล่นโหวต หรือกด **"ปิดรับโหวต"** เมื่อถึงเวลา (วันศุกร์)
3. กด **"Preview ผล →"** — ดูว่าจะคัดใครออกก่อนประกาศจริง (ดูจำนวนจริงเทียบกับที่ตั้งไว้ + คำเตือนถ้ามีคนไทกัน)
4. ตรวจสอบแล้วกด **"✓ ประกาศผล (Publish)"** — ระบบจะ:
   - คิดคะแนนทุกโหวต (+10 ถูกทีม / -5 ผิดทีม) และบวกเข้าคะแนนสะสมอัตโนมัติ
   - **หักคะแนนคนที่ถูกเพื่อนร่วมทีมโหวตผิดหาด้วย -5 เพิ่ม** (ครั้งเดียวต่อสัปดาห์ ไม่ว่าจะโดนกี่คนก็ตาม)
   - คัดคนโดนโหวตเยอะสุดออกเป็น Ghost Mode
   - เปิดรอบถัดไปให้อัตโนมัติ (สถานะ scheduled)

⚠️ กด Publish ซ้ำไม่ได้ (ระบบกันไว้อัตโนมัติ)

### กติกาคัดออกเมื่อคะแนนโหวตเสมอกัน (Tie-break)
ระบบ**ไม่มีการสุ่มเลือกใดๆ**เมื่อคะแนนโหวตเท่ากันที่จุดตัด — ถ้าตำแหน่งสุดท้ายที่ต้องคัดออกมีคนโหวตเท่ากันหลายคน
**จะคัดออกทุกคนที่เท่ากันนั้น** แม้จำนวนที่คัดออกจริงจะมากกว่าที่ Admin ตั้งไว้ก็ตาม (เช่น ตั้งไว้คัด 3 คน
แต่มี 4 คนไทกันที่จุดตัด ผลคือคัดออกทั้ง 4 คน) — เห็นคำเตือนนี้ในหน้า Preview ก่อนกด Publish เสมอ

## ชุบชีวิตผู้เล่น (Revive)
แท็บ **"👥 ผู้เล่น"** — ตารางผู้เล่นทั้งหมด พร้อมทีมจริง สถานะ (Alive/Dead) และจำนวนครั้งที่เคยชุบชีวิต
เมื่อผู้เล่นติดต่อมาขอชุบชีวิต (หลังโอนเงินนอกระบบ) หาแถวเขา (ค้นด้วยรหัสพนักงานหรือชื่อ) แล้วกด
**"Revive"** — ระบบจะเปลี่ยนสถานะเป็น Active ทันที เพิ่มตัวนับ "ชุบชีวิตแล้ว" และบันทึกลง log
(ใครชุบชีวิต เมื่อไร) โดยอัตโนมัติ ผู้เล่นไม่มีทางชุบชีวิตตัวเองได้ — ทำได้ทาง Admin เท่านั้น

## การ์ด & CSR (สำหรับติดตามยอดสนับสนุน/MVP เท่านั้น)
แท็บ **"การ์ด & CSR"** — ใช้บันทึกยอดเงินที่ผู้เล่นสนับสนุนเพิ่มนอกระบบ (ไม่ใช่การ์ดที่ใช้ในเกมแล้ว
เพราะระบบการ์ดฝั่งผู้เล่นถูกตัดออก) ยอดนี้ใช้คำนวณ MVP นักสู้ตอนจบเกมเท่านั้น

## จบกิจกรรม (รางวัล)
แท็บ **"รางวัล"**:
- กด **"✓ ประกาศผู้ชนะทั้งหมด"** → คำนวณอันดับ 1-3 (คะแนนสูงสุด) + MVP นักสู้
  (ยอดซื้อการ์ดเยอะสุด → ยอดเงินสูงกว่า → ซื้อก่อน) อัตโนมัติ
- กด **"จับรางวัล"** สำหรับ Lucky Draw (สุ่มจากผู้เล่นที่ไม่ถูกตัดสิทธิ์)
- ถ้าผู้ชนะ Lucky Draw สละสิทธิ์ กด **"Re-draw"** ระบุเหตุผล ระบบจับใหม่และบันทึกไว้

## Export CSV
แท็บ **"Export CSV"** — ดาวน์โหลดรายงาน 6 แบบ (ผู้เล่น, ผู้เล่น+ทีม, ผู้ถูกคัดออก, การ์ด, CSR, ผู้ชนะรางวัล)

## Audit Log
ทุกการกระทำของ Admin (เปิด/ปิดโหวต, ประกาศผล, มอบการ์ด, จับ Lucky Draw ฯลฯ) ถูกบันทึกอัตโนมัติ ดูได้ที่แท็บ "Audit Log"
